# 收到：一个算法工程师的六年

**武辰 著 · 书稿已交清华大学出版社 · 尚未出版**

[我为什么写这本书：序](https://wuchen2018.pages.dev/articles/received-preface.html)

我做过约六年算法工程师，先后在 OPPO、大疆和顺丰工作。这本书写的就是这六年，也写和我一样在大厂里做算法的人。

我写技术书，在知乎写回答，在 B站讲大模型，一直想办法把难的东西讲成大家听得懂的话。但轮到讲我自己，就不行了。主管找我谈话，我明明有一肚子话想讲，坐在那间小会议室里，几乎什么都没说；爸妈打电话问我累不累，我翻来覆去就是那两个字：还行。这本书想把这些没说出口的话，一件一件，试着说清楚。

书名叫《收到》，因为这是我六年里打得最多的两个字：群里派下来一个活，收到；会上定了一个 deadline，收到；排期被压了一半，收到，我尽量。它不好也不坏，就是一张回执，意思是这件事从现在起归我了。

和我前两本技术书不一样，**这本书不讲技术，讲的是做这份工作的人**。书里一半是我自己的经历，一半是别人的：别人的故事，有一些来自访谈和同事的讲述，更多来自我在各个平台上精读过的三百多篇帖子。书里写到的同事和领导，我没有写名字；别人的故事里能认出身份的名字和细节，我也都做了处理。这本书不劝退，也不劝进，书里有我想明白的事，也有到今天还没想明白的事。

## 写给谁

如果你正坐在工位上，觉得哪里不对，又说不上来，这本书是写给你的。如果你还在门外，正在纠结要不要进这一行，可以先看看门里面的日常是什么样子，再做打算。如果你是算法工程师的爸妈、伴侣或者朋友，想知道他每天到底在忙什么，为什么问起来永远只有一句“还行”，希望这本书能替他多讲几句。

## 全书怎么安排

全书一共十二章。前七章顺着一个人的处境往里走，从怎么进这一行，一直写到身体报了警、话却说不出口；从第八章开始，视角一层一层往外退，退到家里，退到三十五岁那条线，退到 AI，退到公司这台机器；最后一章写离开以后的事，也写那些慢慢缓过来的人。
